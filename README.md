# Champions Boat League Website

GitHub Pages-ready static website for Champions Boat League.

## Files
- `index.html` — main page
- `style.css` — responsive design
- `script.js` — winners, schedule, automatic status and points table

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload these three files.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated Pages URL.

## Data used
The historical champions and the 2026 schedule are based on the supplied source.
